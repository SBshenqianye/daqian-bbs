## 5. 权限组：结论备忘

**不推荐现在做完整权限组。** 关键原因：

1. 后端 90 个 `@PreAuthorize` 里 89 个是 `hasRole`，权限组只覆盖权限点 → 不改造注解就只影响菜单，不影响接口；
2. 与刚完成的 MODERATOR + 板块范围叠加，越权路径组合爆炸；
3. 文档里 grant/revoke、多组优先级、数据范围、前台权限都还没定；
4. 文档原本的动机（版主 + 管理员仍是全局权限）已被 MODERATOR 角色解决。

如果要做，顺序：注解表达式改造 spike → Phase A 只读 → Phase B（先 grant-only）→ C/D。
硬约束：权限组不得授予 `user:grant:admin` / `config:write` / 超管能力；审计从第一天做。
