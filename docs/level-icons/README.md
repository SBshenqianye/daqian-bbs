## 设计口径（对齐默认 24 级方案）

1. **一个大阶段一枚图标**，同一阶段的 3 小档（观 / 悟 / 行）共用——与默认 24 级「同阶段 3 档不额外加标记」一致，避免 16px 头像角标糊成一片。
2. **64×64 纯几何填充**，无位图、无外链、无字体依赖；风格沿用默认图标：厚填充 + 深色投影 + 白色高光。
3. **颜色即稀有度**，由低到高：绿 → 青 → 天蓝 → 蓝 → 靛/紫 → 金 → 红。
4. **造型取该大阶段名称的语义符号**，而不是抽象的 1..7 可数元素（21 级方案的大阶段名本身语义很强）。
