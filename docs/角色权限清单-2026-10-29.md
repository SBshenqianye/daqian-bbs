# 大千智荟 BBS 角色与权限清单（当前实现）

> 版本：2026-11-02  
> 依据：`AccountRole`、`Permission`、`AuthorizationService`、`BoardModerator`、`SelfApprovalPolicy`、`PermissionMatrixController`

## 1. 账号角色

| 角色 | 存储 | 说明 |
|---|---|---|
| `USER` | `user_type='1'` | 普通用户 |
| `ADMIN` | `user_type='2'` | 管理员，全局数据范围 |
| `SUPER_ADMIN` | `user_type='3'` | 超级管理员，支持多个；初始化仅 `id=1` |
| `MODERATOR` | `user_type='4'` | 版主，可登录管理后台，只管理自己板块 |

> 一个账号只有一个角色。版主任职（`bbs_board_moderator`，`status=1`）是板块级数据范围，不改变账号角色。  
> `ADMIN + 板块` 仍按 ADMIN 全局处理；只有 `MODERATOR` 受板块限制。

## 3. 数据范围

| 业务 | MODERATOR | ADMIN / SUPER_ADMIN |
|---|---|---|
| 文章列表/详情/审核/删除/精华 | 仅本板块 | 全部 |
| 举报查看/审核 | 仅本板块 | 全部 |
| 违规新增/取消 | 仅本板块 | 全部；无关联内容的全局违规仅超管 |
| 申诉查看/审核 | 仅本板块 | 全部 |
| 待审采纳列表/审批 | 仅本板块 | 全部 |
| 精华推荐/终审 | 推荐仅本板块；**无终审** | 全部 |
| 工作台统计 | 仅本板块；全局用户/评论指标置 0 | 全局 |
| 用户/配置/组织/敏感词/版主管理 | ✗ | ADMIN 可读，写配置与授予管理员仅超管 |

无板块的 MODERATOR：仍可登录，业务菜单可见，列表为空，写操作返回 403「尚未分配板块，请联系管理员」。

## 4. 自审批策略

| 操作 | 普通管理员 / 版主 | 超级管理员 |
|---|---:|---:|
| 采纳自己的建议 | ✗ | ✓ |
| 审核自己的举报 | ✗ | ✓ |
| 审核自己的申诉 | ✗ | ✓ |
| 审核自己的版主投诉 | ✗ | ✓ |
| 审核自己的精华推荐 | ✗ | ✓ |
| 将自己的帖子设为精华 | ✗ | ✓ |
| 审批自己提问的最佳解答 | ✗ | ✗ |

实现：`SelfApprovalPolicy`；操作人/审核人身份以登录态为准，前端传参与登录态不一致时拒绝。

## 5. 已知限制

1. 权限点仍是“固定角色 + 静态矩阵”，不能在后台动态增删；权限组（Phase B）尚未实施。
2. 前台动作（发帖、评论、举报、申诉等）仍是登录用户默认能力，没有接入权限点。
3. 管理端首次登录（或密码被重置）强制改密（C3）已实施：后端 `FirstLoginPasswordFilter` 拦截管理接口，前端 `/change-password` 强制跳转。
4. 前端菜单/路由只做体验控制，最终权限以后端 `@PreAuthorize` 与服务层校验为准。
5. 权限矩阵页面只读，用于核对代码中的角色/权限与接口注解是否一致。
