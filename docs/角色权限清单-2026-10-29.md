# 大千智荟 BBS 角色与权限清单（当前设计）

> 版本：2026-10-29  
> 依据：`Permission` 枚举、`AuthorizationService`、`BoardModerator` 数据范围、`SelfApprovalPolicy`

## 1. 账号角色

| 角色 | 存储 | 说明 |
|---|---|---|
| `USER` | `user_type='1'` | 普通用户 |
| `ADMIN` | `user_type='2'` | 普通管理员 |
| `SUPER_ADMIN` | `user_type='3'` | 超级管理员，支持多个；初始化仅 `id=1` |

> 版主不是账号角色，是 `bbs_board_moderator(user_id,label_id,status=1)` 的板块数据范围。  
> 当前版主如要登录管理后台，仍需同时具备 `ADMIN` 角色（D1）。

## 3. 版主数据范围

| 业务 | 普通管理员（版主） | 超管 |
|---|---|---|
| 待审采纳列表 | 仅本板块 | 全部 |
| 采纳审批 | 仅本板块 | 全部 |
| 精华推荐 | 仅本板块 | 全部 |
| 文章审核/删除 | 仅本板块 | 全部 |
| 举报查看/审核 | 仅本板块 | 全部 |
| 违规新增/取消 | 仅本板块 | 全部；无关联内容的全局违规仅超管 |

> 申诉审核、用户管理、配置管理、积分调整、版主任命、标签管理、组织管理、敏感词管理仍为全局管理权限。

## 5. 当前已知限制

1. 版主不是账号角色，管理员 + 版主仍拥有 `ADMIN` 的全局菜单和全局权限；如果希望“版主登录后只看到板块页面”，需要新增账号类型/权限组能力（见 `权限管理-设计-2026-10-29.md`）。
2. 用户前台发帖、评论、回复、举报、申诉等动作目前没有接入权限点，属于登录用户默认能力；细粒度控制需权限组能力。
3. 管理后台配置写按钮对普通管理员置灰，但接口仍以 `@PreAuthorize('SUPER_ADMIN')` 兜底。
4. 前端菜单/路由只做体验控制，最终权限以后端为准。
